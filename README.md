 # Personal Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my skills, projects, and contact information.



## Live Demo

🔗 [View Live Site](https://centvin-99.github.io/personal-portfolio)



## About The Project

This was my first major frontend project. I built it to have a real place on the web that represents me as a developer — something I could show to employers and share with others. The goal was to make it look clean and professional while keeping the code simple and well-structured.

---

## Features

- Responsive layout that works on both mobile and desktop screens
- Animated hamburger menu for mobile navigation
- Smooth scrolling between sections
- Auto-scrolling projects marquee that pauses on hover
- Working contact form with a success message on submission
- Dark theme with red accent colours

---

## Technologies Used

- HTML
- CSS (Flexbox, animations, media queries)
- JavaScript (DOM manipulation, event listeners)
- Google Fonts (Poppins)

---

## What I Learned

Building this project taught me how to structure a multi-section webpage properly and think about layout from the start. I got hands-on experience with CSS Flexbox for both the navbar and the hero section, and learned how media queries work in practice — not just in theory. Implementing the hamburger menu helped me understand how JavaScript and CSS classes work together to create interactive UI elements. I also learned how to create a seamless CSS animation for the marquee, and why duplicating cards is necessary for the loop to look smooth.
